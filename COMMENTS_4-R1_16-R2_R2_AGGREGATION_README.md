# Comments 4-R1 / 16-R2: complementary R2 aggregation

The nested model-selection/evaluation procedure is unchanged. This reporting analysis addresses the sensitivity of R2 to aggregation when outer test folds are small.

Run after the nested-CV script:

```bash
python src/revision_comments_4_R1_16_R2_r2_aggregation.py
```

The script reads the stored outer-fold metrics and repeat-level pooled out-of-fold predictions generated by `revision_comments_4_R1_16_R2_nested_cv.py`. It does not refit models. It reports, for each target, the mean and median fold-level R2, the fraction of positive outer-fold R2 values, the fold-level range, and the mean/SD/range of R2 computed after pooling all out-of-fold predictions within each of the 20 repetitions.

Key values:
- Pr: mean fold R2 = -0.083; repeat-pooled OOF R2 mean = 0.321.
- SR: mean fold R2 = -0.074; repeat-pooled OOF R2 mean = 0.033.
- Qm: mean fold R2 = 0.762; repeat-pooled OOF R2 mean = 0.846.
- AF: mean fold R2 = 0.712; repeat-pooled OOF R2 mean = 0.742.

For Pr, 63% of the 100 outer folds had positive R2 and the median fold R2 was 0.171, but a small number of extreme negative fold-level R2 values pulled the arithmetic mean below zero. The positive repeat-pooled R2 therefore indicates some aggregate signal, while the fold dispersion and negative nested LOFO R2 still argue against high-resolution Pr gating or a stable transferable predictive claim.
