# Archive policy

Files under `archive/` are retained only for historical traceability. They are not authoritative manuscript outputs and are not part of the canonical reviewer-revision run order.

- `legacy_pre_revision_xai/`: superseded consensus-score/in-sample XAI artifacts.
- `legacy_pre_revision_candidate_ranking/`: superseded model-ranked candidate/design-atlas artifacts; the original 17-candidate list is retained only as the input to the reviewer-requested bootstrap sensitivity analysis.
- `intermediate_revision_scripts/`: one-time patch helpers and superseded/intermediate analysis scripts.
